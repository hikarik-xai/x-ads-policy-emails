X広告よりご案内です

日頃よりX広告をご活用いただき、誠にありがとうございます。
X広告のご出稿に際して、プロフィール設定および広告に使用するポスト内容（投稿テキスト）についてご案内申し上げます。

つきましては、下記をご参照いただき、プロフィールを修正・ポリシーに準拠したポストを作成のうえ、 新規でキャンペーンを立て直すようお願いいたします。

1. プロフィール設定について

お客様のXアカウントは、プロフィール設定が広告出稿の必須要件を満たしていない可能性があります。

プロフィールの設定をご確認ください

※下記1〜7は広告出稿に必須です。

❶ ヘッダー画像
サービス内容がユーザーに魅力的に伝わる画像を利用してください
❷ プロフィール画像（アイコン）
ブランドロゴや企業が分かる画像を利用してください
❸ アカウント名
企業・ブランドに関連するアカウント名を使用してください
❹ 認証バッジ
認証バッジを獲得してください（Xプレミアムへ加入）
❺ ユーザー名（@ハンドル）
初期設定のランダムな文字列は使用しないでください
❻ Bio（説明文）
企業やブランドの概要・特徴を記載してください
❼ URL
企業・ブランドの公式サイトなど、一貫性のあるURLを設定してください

注意事項

  • 場所、生年月日など他の項目の設定は任意となります。
  • 生年月日に企業の設立日などを設定する場合、アカウント作成時点から13歳未満になるような生年月日を設定すると、規約違反となりアカウント停止の対象となる場合がありますのでご注意ください。

上記7つの条件を満たしていない場合は、プロフィールを修正のうえ、新規でキャンペーンを立て直すようお願いします。

2. 広告に使用するポスト内容（投稿テキスト）について

お客様が広告に使用したポストには、広告配信できない要素が含まれている可能性があります。

#（ハッシュタグ） / #️⃣ / ✅ / テキストURL

これらを投稿テキストに含むポストは、現在広告が配信できません。

　　　　　　　　　

本文に # や URL が含まれるポストは、広告用ポスト・オーガニックポストを問わず「広告配信」にご利用いただけません。オーガニック(広告利用しない)での利用は引き続き可能です。 　　　　　　　　　

NG例

現在、# や URL を含むポストを使用しているキャンペーンは、Halted になり配信が出ていない可能性があります。ポリシーに準拠したポストを作成のうえ、新規でキャンペーンを立て直すようお願いします。

プロフィール設定・ポスト内容どちらも違反している場合は、両方とも修正のうえ、新規でキャンペーンを立て直すようお願いします。
